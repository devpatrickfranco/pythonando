# Sistema de login

- Cadstro:
    - Nome
    - Email
    - Senha

- Login
    - Email
    - Senha

# RF

- Deve ser possivel cadastrar um usuario
- O usuario deve poder logar no sistema
- A senha do usuario deve ter no minio 10 caracters.

# RNF

- A senha deve ser criptografada
- Não pode existir o mesmo email pra dois usuarios
